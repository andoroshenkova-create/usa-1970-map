USA 1970 National Atlas map prepared for Knight Lab StoryMapJS

Original image size: 2048 x 1416 pixels
Zoomify tile size: 256 x 256
Zoom levels: 4 (0 through 3)

For StoryMapJS:
- Map Type: Gigapixel
- Treat As: Image (recommended for this historical map)
- Max Image Size: 2048 x 1416
- Zoomify URL: the PUBLIC WEB URL of this folder (the folder containing ImageProperties.xml and TileGroup0)

Important:
This package is a zoomable image for StoryMapJS. StoryMapJS lets you place points by clicking directly on the historical image; it does not automatically use latitude/longitude in Gigapixel mode.
